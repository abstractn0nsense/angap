# 사진 보내기 도우미

노년층 사용자가 Android 메시지 앱에서 자녀에게 사진을 보내는 과정을 쉽게 따라 하도록 돕는 앱입니다.

## 현재 상태

이 저장소는 첫 단계인 Android 프로젝트 뼈대만 포함합니다.

- Kotlin + Jetpack Compose 기반
- 단일 `app` 모듈
- 큰 글씨와 버튼을 사용하는 단계별 사진 전송 안내 화면
- 글자 크기·색 대비·버튼 높이를 높인 노년층 중심 화면 구성
- 사용자가 허용한 경우에만 작동하는 단계별 오버레이 안내
- 표준 Android 메시지 작성 화면을 여는 시작 흐름
- 사진·메시지 데이터 접근 기능 없음

## 개발 환경

- 최신 안정판 Android Studio
- JDK 17
- Android SDK Platform 35 이상

Android Studio에서 이 폴더를 열고 Gradle 동기화를 완료한 뒤 실행하세요.

## 기기 확인 순서

1. 앱을 열고 단계 안내에서 이전·다음·휴대전화의 뒤로 가기가 자연스럽게 동작하는지 확인합니다.
2. `다른 앱 위에서 안내 보기`를 선택하고, Android 설정에서 권한을 허용합니다.
3. 메시지 작성 화면이 열리고 화면 아래 안내창이 표시되는지 확인합니다.
4. 오버레이의 닫기 버튼으로 안내창이 사라지는지 확인합니다.
5. Android 설정에서 오버레이 권한을 해제한 뒤 다시 시도해, 권한 설정 화면으로 안내되는지 확인합니다.

## 다음 단계

1. 단계별 사진 전송 안내 화면 구현
2. 사용자가 허용한 경우에만 동작하는 Android 오버레이 구현
3. 메시지 앱을 여는 흐름과 접근성 개선

## 개인정보 원칙

이 앱은 메시지나 사진을 읽거나 전송하지 않습니다. 이후에도 실제 기능에 필요한 최소 권한만 사용자에게 명확히 설명한 뒤 요청합니다.
